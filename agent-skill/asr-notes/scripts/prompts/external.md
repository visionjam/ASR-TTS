**摘要规则（重要）**
- 每条论点后面附一句从转写里**逐字复制**的原话，写成：（原文："……"）
- 必须是原文里连续存在的一段，一个字都不要改：不改标点、不加空格、不合并两句、
  不用省略号拼接。可以只摘半句，宁短勿改。
- 摘引控制在 60 字以内。摘不出来（原文太碎、或你的概括已经不是他的措辞）就**不要写**
  （原文：…），只写论点本身。
- 脚本会拿这句去逐字核对：对得上的标 [原话]，对不上的降级为 [归纳]。凑引文没有意义。

硬性要求：
- 不评价、不建议、不站队，不写"作者应该……"

  讲话人不是使用者，用这些字段等于替别人做自我检讨

- 不要自己添加 [原话] / [归纳] 这类方括号标记，脚本会标注

- 广告段不要写进「这期在讲什么」「关键论点」「论据与数据」，它在正文里存在，但不属于内容
