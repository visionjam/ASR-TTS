## 实测结果（2026-11-24，豆包 2.0，zh_male_liufei_uranus_bigtts）

二十条里十九条念对了，只有 14 号不对：

- **14 `A→B` 读成「右箭头」** → 规则已处理，替换词改成「到」（不是「变成」，
  原稿里箭头多半表示路径方向，不是状态变化）。
- 02 `80%`、03 `7.67%`、04 `1/10`、15 `手机+互联网` 全部念对 → 这三条 probe
  规则已经删掉，不再做无用改动。
- 06 `RTX 5090` 念法可接受 → 不加型号规则，词典入口留着备用。
- 19 `《理性》`、20 破折号都没念出来 → 不加规则。
- 11 `120km/h`、12 `3000m²`、13 `-5℃`、16 `3~5 天`、17 `±3` 全部念对
  → 对应的 core 规则也删了，字幕保持原样，不做视觉上的加长。

**换 provider 之前要重跑这二十条**，DeepSeek 的表现没测过，别把豆包的结论
当永久事实。

## 结论怎么落

- 「应该」对上了：那条不用管。
- 引擎念错、但 core 规则已经处理：把样本从 probe 挪进 core，或确认现规则够用。
- 引擎念错、规则还没管：在库根 `verbalize.tsv` 加一行 `原文<TAB>读法`，不用改代码。
- 引擎本来就读对、规则却改了：把那条规则从 core 降回 probe 或删掉。
